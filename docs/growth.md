# M3：四职业1–5级固定成长（已实现）

更新：2026-10-18，Asia/Shanghai。当前内容 `0.3.0-m3`，规则 `0.3.0-provisional`，JSON存档格式仍为1，角色成长快照标记 `growth_version=1`。本页替代原M0八级候选表作为当前可玩范围；六职业八级仍是后续目标。

## 运行数据与升级

`content/pack.json` 保留历史1级切片内容及几何验证；`content/growth.json` 提供四职业各五份快照和九项新能力、六件装备。Engine加载后合并内容，校验新effect与被动白名单、法术位、资源、等级、引用、装备位和默认装备。没有空effect按钮。

快照包含属性、固定HP、熟练、速度、豁免熟练、装备、装备熟练、被动、能力、职业资源与法术位。运行防御由装备与属性重新计算。职业创建后固定；安全阶段的“固定职业升级”直接应用下一等级，不选择加点、专长或亚职。当前无经验值、奖励节点和战役升级条件；M3安全阶段允许逐级验证到5级，正式战役节奏由M4接入。

升级按生命上限差值增加当前生命，保留受伤量；0生命与死亡角色不会被升级复活。保留已经消耗的法术位、资源和药水，新增容量可用；保留自选装备与取消准备的法术，自动准备新解锁法术。援助术的上限加成在升级中保留。

## 实际开放的职业包

| 职业 | 1级 | 2级 | 3级 | 4级 | 5级 |
| --- | --- | --- | --- | --- | --- |
| 战士 | 防御风格：穿甲防御+1；回气1d10+等级 | 动作如潮：免费获得一个动作，短休一次 | 战技鼓舞：8临时生命，倒地目标先恢复1生命；4优越骰 | 力量18 | 一个攻击动作可分两次攻击 |
| 武僧 | 无甲无盾感知防御；武艺附赠打击；2气；疾风连击两次徒手攻击 | 3气、无甲无盾速度+3米；耐心防御已开放 | 4气；武艺骰升1d6 | 敏捷18、5气 | 6气；额外攻击 |
| 法师 | 火焰箭、魔法飞弹、法师护甲；奥术回想1点 | 塑能保护（当前用于火球友军免伤） | 灼热射线；回想2点 | 智力18 | 火球术、回想3点；火焰箭2d10 |
| 牧师 | 圣火、治愈真言、疗伤、祝福；生命领域治疗+2+环级 | 引导神力：9米内可见队友恢复3×等级 | 援助术：9米内可见队友上限与当前生命+5，可升环 | 感知18 | 群体治愈真言；圣火2d8 |

气点=等级+1；耐心防御在本轮缩减包从1级随气点一起开放（与BG3逐级解锁不同）。回气、动作如潮、优越骰、气点、引导神力短休恢复。奥术回想点数=向上取整(等级/2)，只能安全阶段按法术位环级花点，每点恢复一环容量；短休不恢复回想点。重新演练/新建开发局刷新全部资源。

额外攻击只接续普通攻击，不提供施法、疾走或反应次数；可分配不同目标。动作如潮提供的新动作也可产生一组额外攻击。附赠打击、疾风连击与借机攻击不生成额外攻击。武僧穿甲或持盾时失去无甲防御、移动加速与本包武艺技；徒手退回固定1+力量。

法师本轮固定已学集为火焰箭、魔法飞弹、法师护甲，加3级灼热射线、5级火球术；不做抄卷。牧师集为圣火、治愈真言、疗伤、祝福，加3级援助、5级群体治愈真言。戏法不用准备；带环法术必须准备。上限=等级+施法属性修正，领域恒定准备不计数：祝福/疗伤，3级加援助；恒定法术不可取消。本包数量较小，默认可全部准备，但取消准备后确实不能施放。

魔法飞弹升环增加一枚；治疗每环加一骰；祝福每环多一个目标；灼热射线每环多一条；援助每环多5生命。法师护甲可用高环位但不增加效果。当前最高3环，所以3环法术无更高升环入口。射线和飞弹暂不拆分目标；火球以可见敌人为中心，6米球形范围，不提供地面选点，爆炸可结算范围内隐藏敌人但不泄露其日志/数据。塑能保护使友军免伤；其他目标敏捷豁免减半。援助重施仅补更高环的差额，不能重复治疗。

## 装备与熟练

装备位为主手、副手、护甲。有长剑、巨剑、匕首、木杖、钉头锤、徒手，皮甲/鳞甲/链甲与盾牌。背包是本轮验证用固定器材柜，不是掉落、购物或无限生成战役奖励系统。换装仅在胜利安全阶段，战前组合由独立开发入口设置。

| 类别 | 效果 |
| --- | --- |
| 无甲 | 10+敏捷；武僧无盾额外+感知 |
| 皮甲 | 11+敏捷 |
| 鳞甲 | 14+敏捷（最多+2） |
| 链甲 | 16；不加敏捷 |
| 盾牌 | 防御+2；不能与双手巨剑共存 |
| 战士防御风格 | 穿护甲再+1，起始链甲+盾为19 |
| 武器 | 单手长剑1d8、巨剑2d6、匕首1d4、木杖/钉头锤1d6；力量，匕首或合法武僧武器可用敏捷 |
| 未熟练武器 | 仍可持用，但攻击不加熟练；伤害仍加相应属性 |
| 未熟练护甲/盾 | 可以穿戴，但攻击劣势，并阻止所有施法，包括戏法 |

战士熟练全部本包装备；牧师熟练简易武器、所有甲和盾（生命领域）；武僧熟练简易武器；法师熟练匕首/木杖。穿甲或卸甲会即时重算防御、攻击属性和速度；法师护甲只作用于无甲目标，盾牌加值仍保留。非武僧空主手为普通徒手固定1+力量。

本轮是可玩四职业1–5级能力子集，不是完整BG3职业复刻。未开放：完整亚职技能列表、震慑、拨挡、缓落、散打变式、更多战技、护盾/反制、其他二三环法术、完整领域法术、抄卷、完整种族/背景/技能检定、更多装备位/附魔/双持/投掷、长休营地、经验节点。未开放内容不出现在技能菜单，不注册占位effect。六职业八级、20场战役、商店与Boss仍不在本轮。
