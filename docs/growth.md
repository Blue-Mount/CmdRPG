# 固定成长草案（M0，尚未实装）

记录日期：2026-10-11。运行内容只包含 `fighter`、`monk`、`wizard`、`cleric` 的 1 级能力子集。以下表格是规划输入，不会被 `load_content` 读取，也没有 2 至 8 级升级入口。`rogue` 与 `warlock` 不能用于当前建队。

成长以 [SRD 5.1 官方 PDF](https://www.dndbeyond.com/attachments/39j2li89/SRD5.1-CCBY4.0License.pdf)作为基础核对索引，最终应按 [rules.md](rules.md)记录的 BG3 指定构建完成差异核验。战斗大师不在 SRD 5.1 开放职业选项中；[Larian 职业公告](https://baldursgate3.game/news/community-update-20-a-dragonborn-a-half-orc-a-monk-walk-into-a-tavern_76)确认 BG3 职业方向并说明武僧经过改动，但不能充当逐级技能表。下文遇到未取得一级来源 / 实测的数值时直接保留待定。

## 固定参数与缺口

M3 放行前，每个职业必须提交八份完整机器可读快照、所有能力 effect、准确来源或实测、合法装备 / 熟练、资源刷新、法术准备与专长变更记录。任何一项仍为“候选 / 待核验”时，不能把对应职业等级加入可选菜单。
