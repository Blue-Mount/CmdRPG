# 文字客户端

当前交付是 M1/M2 战斗切片：战士、武僧、法师、牧师的 1 级模板，一场原创前哨战。可查看、移动、攻击、施法、选择借机攻击反应、结束操作、战败重试及战后短休。尚无完整战役、升级、购物或换装入口。

## 本地开始与恢复

在项目目录运行，Python 标准库即可启动本地模式；使用与远程服务相同的核心和 SQLite 仓库。

```powershell
python -m client --new --name "晨光小队" --classes fighter,monk,wizard,cleric --seed 7
python -m client
python -m client --run 周目ID
python -m client --db data/another.sqlite3 --new --classes fighter,fighter,wizard,cleric
```

恰好四名队员，允许重复职业。每个成功动作与反应选择自动保存。直接退出或关终端不会按现实时间推进回合。`--run` 与 `--new` 互斥。

`data/client.json` 默认只保存最后一次连接和周目 ID。本地记录数据库绝对路径；远程记录服务器地址。可用 `--config 路径` 或 `CMDRPG_CLIENT_CONFIG` 指定独立记录。多个终端请分别指定 `--config`，以免共用未确认请求记录。

## 远程连接

远程客户端用标准库 `urllib`，不需要安装 FastAPI。代码须包含 `client/` 包。

```powershell
$env:CMDRPG_URL = "https://你的游戏服务地址"
$env:CMDRPG_TOKEN = "你的独立凭据"
python -m client --new
python -m client --run 周目ID
```

也支持 `--url`、`--token` 和 `--timeout 秒数`。推荐通过环境变量提供凭据，避免进入 shell 历史。凭据不会保存到配置、请求恢复记录或玩家日志。远程记录会保留上次服务地址，下次可直接设置 `CMDRPG_TOKEN` 后运行 `python -m client`。`--db` 显式选择本地模式；`--url` 与 `--db` 互斥。客户端不会跟随 HTTP 重定向，以免向另一个服务发送凭据。

非回环服务地址必须使用 HTTPS；HTTP 只允许 `localhost`、`127.0.0.1`、`::1` 等本机回环地址用于本地联调。超时须为有限且大于零的秒数，不能使用 `nan` 或 `inf`。

## 不记命令的默认玩法

启动后直接显示地图与四名角色。首页数字 `1` 至 `4` 对应四名队员，标明“可操作”与暂时不能操作的原因；当前选中的角色在地图上突出显示。选择一个角色后，立即显示普通行动和全部已拥有的职业技能。技能使用中文名称，注明动作或附赠动作成本、法术位、剩余次数及简短作用；不可用技能仍显示，例如“法术位不足”“需要先攻击”。

每层提示都写明当前角色、当前行动和所处阶段。按以下顺序操作：

1. **选角色**：在首页输入队员编号。
2. **选行动或技能**：输入中文菜单旁的编号，例如“移动”“普通攻击”“火焰箭”“治愈真言”或“结束角色操作”。
3. **选目标或目的地**：攻击、治疗、施法输入目标编号；祝福输入多个编号，例如 `1,2,3`。移动可以输入常用目的地编号，或精确坐标，例如 `D6`、`G6`。
4. **查看自动预览**：确认成本、影响、命中率或豁免概率，以及危险、专注替换或借机攻击。
5. **执行或返回**：输入 `c` 确认，输入 子菜单中 `0` 返回上一层重新选择。输入 `q` 随时离开。

数字始终只选择当前显示的条目，预览页输入数字不会提交行动。攻击、治疗、移动等普通行动后仍保留当前角色；“结束操作”确认后切换到下一位可操作角色。所有实际行动仍由服务端校验与结算，菜单不能绕过视线、射程、资源或版本限制。

目标列表显示名字、生命、距离与相关概率，并保留不可用目标及具体原因，例如“遮挡”“超出射程”。选中不可用目标不会写入或推进战斗。已死亡敌人不再作为攻击或施法目标。治疗的效果无需命中检定；圣火显示敌方豁免失败概率；自动命中的法术会注明确定效果。多目标技能仍逐项检查目标，最终预览计算整个目标组合。

距离使用包含地形高度的三维直线计算，供射程判断；移动成本使用实际可走路径，二者可能不同。例如 P2 位于 K4 台阶（高 1.5 米），E3 位于 L4 高台（高 3 米）：水平距离 1.5 米、高差 1.5 米，直线距离为 `√(1.5² + 1.5²) ≈ 2.12 米`，因此超出 1.5 米的近战触及。移动只走相邻可通行格，还要计入困难地形和绕行，不以这个直线距离扣除移动。

反应暂停战斗时显示中文菜单：`1` 选择接受、`2` 选择拒绝，随后用 `c` 确认，`0` 返回重新选择。离开后待选反应仍保存在服务端，重新启动会恢复到同一反应窗口。

## 看地图和移动

地图的列从左至右为 A、B、C……，行从上至下为 1、2、3……。地图格使用固定三字符宽度的 ASCII 符号，并用 `|` 分隔每格，避免连片墙、高台或危险地面粘在一起。`P2*` 等带 `*` 的角色编号表示当前选角。旁边的图例将符号对应到角色编号、中文名称、墙 `#`、困难地形 `:`、危险地面 `!`、台阶 `/`、高台 `^` 及门洞 `<>`。颜色仅为辅助，没有颜色仍能识别。角色名字不放进地图格，避免中文文字宽度导致错位。死亡敌人不占格，尸体在图外另列，原位置可正常通行。

简短局势说明会解释断墙、门洞、台阶、高台与遮挡关系。西侧队员应先接近门洞，穿过断墙后可接近瞭望台台阶；射程足够仍可能被墙或高差挡住射线。隐藏敌人不会出现在地图或选项中。

选择“移动”后，地图用 `+` 展示按真实合法路径计算的本回合可达格子；`+!`、`+^` 等组合同时保留危险或高台地形。困难地形、台阶、高差和已知占位都参与计算。常用目的地同时显示到达成本、本回合能否到达及战术作用；不可达目的地保留原因。选择目的地后自动显示整条路径、移动成本、沿路危险地面和可能遭到的借机攻击，确认后才移动。当前只支持编号和坐标选格，方向键选格尚未实现。

默认输出保留战术摘要与本次结果。首次选择角色会展示简短作用；普通行动后显示紧凑菜单，保留全部技能、成本、剩余资源和不可用原因。行动菜单的“技能与规则说明”“详细日志”“队伍资源”“地图”可以按编号展开；也可输入 `party` 查看队伍资源、`map` 重看地图、`inspect G6` 查看格子，或 `log 10` 展开最近计算明细。

## 一次试玩示例

```powershell
python -m client --new --seed 42
```

首页选择 **3 号法师**，在行动菜单选择“移动”，输入 `G6`，查看路径并输入 `c`。在法师菜单选择“火焰箭”，输入一个可用敌人的编号，查看命中率并确认。在法师初始位置直接施法会遇到断墙遮挡，目标菜单会说明原因。用 `0` 可以从预览返回目的地或目标列表，从列表返回行动菜单，再返回首页。

继续选其他角色：武僧先武器攻击后会开放附赠徒手攻击；战士可用回气，牧师可选择治愈真言、疗伤术或祝福。结束某角色操作后系统选中下一位；敌方行动触发反应时按反应菜单选择并确认。战斗所有动作与反应都自动保存。这里的行动、目标编号以当前显示为准，局势变化后可能不同。

## 胜利之后

击败全部敌人后，自动进入独立战后菜单，角色操作入口结束。当前内容仅有这一场前哨战，没有下一关、升级、商店或可拾取的尸体掉落。

| 编号 | 操作 |
| --- | --- |
| `1` | 全队短休：显示每名队员的恢复预览，`c` 确认一次为全队休息 |
| `2` | 查看队伍生命、法术位与资源 |
| `3` | 用当前阵容重开新周目，`c` 确认后新建独立存档 |
| `4` | 查看战场地图，尸体另列且不挡路 |
| `5` | 展开详细日志 |
| `6` | 查看战利品说明；本场未配置掉落，不能摸尸体 |

短休每次消耗 **全队共用的 1 次短休**，本周目共两次；所有存活队员恢复一半最大生命（向上取整并受生命上限限制），恢复战士回气等可短休资源。短休可以救起倒地队员，但不能复活已死亡队员；不恢复法师与牧师的法术位，也不补充药水。它无需逐个选择角色。预览不扣资源，`0` 取消回到战后菜单；次数用尽时仍显示原因。

选择重开周目并确认，会保留队伍名称和四名队员的职业，重新开始本场前哨战；原周目保存在数据库中，屏幕显示旧周目 ID，之后可用 `python -m client --run 旧周目ID` 查看。取消重开不会创建存档。新周目 ID 会成为默认恢复对象。也可输入 `q` 保存胜利结果并离开，或使用命令行 `python -m client --new --seed 42` 重新试玩。

## 命令快捷入口

输入 `help` 查看全部当前支持的命令。以下旧命令均保留，熟悉后可直接使用。

| 命令 | 用途 |
| --- | --- |
| `resume` | 读取已保存的最新局势、可操作角色与反应窗口 |
| `party`、`map` | 资源摘要、只标记可见角色的文字格图 |
| `inspect E1`、`inspect G6` | 可见角色参数、已知静态地形；隐藏角色不进入客户端 |
| `actions P1` | 职业能力、成本和不可用原因 |
| `preview move P2 G6` | 路径、移动成本、可见危险及反应提示 |
| `preview attack P1 E1` | 攻击预览 |
| `preview cast P3 fire_bolt E1` | 施法预览 |
| `preview cast P4 healing_word P1 slot=1` | 指定法术位的治疗 |
| `preview cast P4 bless P1,P2,P3 slot=1` | 逗号分隔的多个目标 |
| `preview ability P1 second_wind` | 使用战士回气 |
| `preview ability P2 unarmed_strike E1` | 武僧攻击动作后使用附赠徒手攻击 |
| `preview cast P3 mage_armor P3 slot=1` | 对法师或武僧施放护甲 |
| `preview dash P2`、`preview disengage P2`、`preview dodge P2` | 疾走、撤离、闪避 |
| `preview help P1 P2`、`preview potion P1` | 协助、喝药水 |
| `do 1` | 确认预览编号 |
| `end P1` | 结束该队员操作，必要时推进到下一次玩家决策 |
| `react accept`、`react decline` | 接受或拒绝已保存的待选反应 |
| `rest short` | 胜利后全队短休一次；默认菜单 `1` 会先预览再确认 |
| `retry` | 仅战败时恢复战前状态；不是网络重试 |
| `resend` | 重发原请求，恢复丢失的写入回执 |
| `log 10` | 最近十条玩家可见事件及计算信息，支持 1 至 100 条 |
| `quit` | 离开终端 |

支持 `readline` 的终端可以按 Tab 补全命令、可见角色和能力编号；没有该模块的终端照常使用文本与数字菜单。完整行动也可直接输入，例如 `attack P1 E1`。语法错误不会提交写请求；目标合法性、视线、范围与资源仍由核心统一校验。

## 预览过期与连接中断

每个预览绑定服务器状态版本。执行前读取最新视图；其他终端改变局势时拒绝提交过期预览，并提示重新选择、重新预览。也可重新输入 `preview` 快捷命令。返回、取消、读请求、菜单选项和预览不会消耗资源或随机数。

写入前将请求 ID、状态版本和原始命令保存到同目录的 `client.pending.json`。如果响应超时，服务器可能已经提交动作；此时只能输入 `resend` 或数字 `9`，客户端会重发完全相同的请求和 ID。重输同一个未确认的 `do 编号` 也复用原请求。服务器返回已有回执，不会再次攻击或掷骰。

退出时保留未确认请求；下次启动自动重发原请求，恢复回执后删除该记录。配置与恢复记录都不含 token。未确认请求存在时不能新建周目、切换服务器或提交其他动作；必须先恢复原回执。不要删除恢复记录后重新提交相同动作。`retry` 会明确恢复战前游戏状态，与 `resend` 的网络回执恢复不同。


## M3成长、装备与独立试玩

推荐开发验收：`python -m tools.dev_play --level 5`，或 `--levels 2,3,4,5 --http`。只在临时目录保存开发数据库与客户端记录，启动时打印恢复命令。`--equip P1:off_hand:none --equip P1:main_hand:greatsword` 可验证双手武器；`--prepare P3:magic_missile,fireball` 验证取消准备后的限制。

`party` 显示中文装备、属性、熟练、额外攻击、法术位、准备与职业资源。胜利结算的7–10号分别进入P1–P4成长装备菜单；可固定升级、穿戴、卸下、切换准备、奥术回想。每次选择先预览，`c`确认，`0`取消。开发局另有11号重新演练，沿用当前等级/装备/准备并刷新资源，普通周目无该入口。

快捷预览：`preview levelup P1`、`preview equip P1 off_hand none`、`preview equip P1 main_hand greatsword`、`preview prepare P3 magic_missile,fireball`、`preview recover P3 2`、开发局`preview practice`，再`do 编号`。升环仍可用 `preview cast P3 magic_missile E1 slot=3`；群体法术无需目标，例如 `preview cast P4 aid slot=3`。这些命令本地/HTTP完全共用预览和确认事务。

本轮胜利后的升级是安全阶段的逐级验证入口，没有战役经验节点。新开普通独立周目仍从1级开始；开发局“重新演练”保留新成长与装备。没有购物、战役奖励、下一关或完整Boss。
