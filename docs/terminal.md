# 战斗面板与配装（2026-10-27）

角色卡、角色行动页及 `party` 显示当前装备对应的命中加值、每动作与当前剩余攻击次数、法术攻击/DC、AC、移动速度与剩余移动，明确武器/护甲/盾牌熟练。武僧另列徒手命中和气点当前/上限，施法者列法术位当前/上限。命中加值不含具体目标引起的高低地、祝福或优劣势，实际命中率以目标预览为准。

祝福显示施法来源与各自剩余回合；牧师卡显示专注。专注结束事件在真实结算中突出显示原因，最近一次结束原因持久化并可在角色卡/party查到。营地与进入下一战也说明清除专注的原因。

商店购买和换装预览新增“变化摘要”，数值变化显示正负差值，例如武器命中+2、AC-1，完整前后属性仍可查。气点上限装备不会在穿戴时补气，短休/营地恢复后才可使用新增额度。

# 优势、劣势与骰子显示（2026-10-27）

选目标与确认预览明确显示普通掷骰、优势（掷两次d20取高）、劣势（掷两次d20取低），或优势与劣势抵消（只掷一次），并列出来源，例如目标被震慑、目标闪避、远程攻击时有敌人贴身、护甲或盾牌未熟练。高低地命中加值与优势/劣势是不同规则。

真实结算直接显示所取骰子，例如“劣势：d20 [7, 8]，取低 7；劣势来源：目标正在闪避”，随后列命中加值、祝福、目标AC与结果。敌我攻击、借机攻击和多段攻击共用这套说明；不同目标分别显示。豁免结算同样说明闪避带来的敏捷豁免优势及取值。魔法飞弹不进行攻击检定，不显示虚构的优势/劣势。伤害计算中的骰子列表仍按伤害骰相加。

旧存档可继续，新增说明适用于更新后生成的预览和结算；已保存的历史事件不改写。卡片用 `n/p` 查看完整预览，用 `]/[` 翻阅完整结算；文字菜单显示同一内容。

# 决策卡界面（2026-10-23，推进 C）

`python -m client --ui auto` 为默认入口：支持 VT 的交互终端达到110列×36行时启用固定区域 TUI，否则自动使用原文字菜单。也可显式指定 `--ui cards` / `--ui plain`。开发试玩可用 `.\.venv\Scripts\python.exe -m tools.dev_play --level 5 --ui cards`，只创建独立临时存档。

卡片复用同一 Client、正式 options/preview、反应与 SQLite 提交链路。左侧地图只呈现可见单位、最后目击与已知地形；右侧依次选择角色、行动、目标和确认；下方显示已执行结果或按需详情。角色卡显示生命、动作/附赠/反应/移动与常用行动短名称。完整行动列表没有战术排序，也不固定限制为三项；不可用技能保留原因。选技能后显示效果、成本与剩余次数，输入 `rules` 展开所选技能规则。目标和移动预览仍由核心计算。

| 输入 | 行为 |
| --- | --- |
| `n` / `p` | 当前决策列表下一页 / 上一页；编号始终对应完整列表 |
| `mn` / `mp` | 地图与图例下一页 / 上一页 |
| `]` / `[` | 下方结果或详情下一页 / 上一页 |
| `rules` | 展开所选技能规则；未选技能时显示所选角色完整规则 |
| `result` | 重看本次会话最近一次已确认回执的全部事件与实际资源变化 |
| `details` | 展开该次回执全部计算；历史仍可用 `log 10` 查询 |
| `0` / `c` / `q` | 返回并取消本次确认 / 确认 / 退出 |
| `plain` | 切回文字菜单，保留当前选择、预览和存档 |

多段攻击的正式预览显示至多段数；火球列出每个可见受影响目标的豁免失败概率，计入祝福、闪避与豁免熟练。执行后按真实事件顺序显示每段命中/未命中、暴击、伤害、击败、治疗和状态变化，并显示回执前后的实际资源变化。翻页只影响呈现，不写入、不掷骰。预览位于决策区，已确认结果保留在下方，不会被下一次未执行预览替换。

终端缩小到最低尺寸以下时自动切回文字模式；退出和异常会恢复终端屏幕。无新增第三方运行依赖。升环等快捷命令继续可用，例如 `preview cast P3 scorching_ray E1 slot=3`，再按 `c`；魔法飞弹/射线现在支持逐段分配，火球支持地面选点，详见下文。

## 本地开始与恢复

在项目目录运行，Python 标准库即可启动本地模式；直接调用规则核心与本地 SQLite 存档。

```powershell
python -m client --new --name "晨光小队" --classes fighter,monk,wizard,cleric --seed 7
python -m client
python -m client --run 周目ID
python -m client --db data/another.sqlite3 --new --classes fighter,fighter,wizard,cleric
```

恰好四名队员，允许重复职业。每个成功动作与反应选择自动保存。直接退出或关终端不会按现实时间推进回合。`--run` 与 `--new` 互斥。

`data/client.json` 默认只保存本机存档路径和周目 ID。记录本机数据库绝对路径。可用 `--config 路径` 或 `CMDRPG_CLIENT_CONFIG` 指定独立记录。同一数据库只允许一个游戏或同步进程使用。

## 不记命令的默认玩法

启动后直接显示地图与四名角色。首页数字 `1` 至 `4` 对应四名队员，标明“可操作”与暂时不能操作的原因；当前选中的角色在地图上突出显示。选择一个角色后，立即显示普通行动和全部已拥有的职业技能。技能使用中文名称，注明动作或附赠动作成本、法术位、剩余次数及简短作用；不可用技能仍显示，例如“法术位不足”“需要先攻击”。

每层提示都写明当前角色、当前行动和所处阶段。按以下顺序操作：

1. **选角色**：在首页输入队员编号。
2. **选行动或技能**：输入中文菜单旁的编号，例如“移动”“普通攻击”“火焰箭”“治愈真言”或“结束角色操作”。
3. **选目标或目的地**：攻击、治疗、施法输入目标编号；祝福输入多个编号，例如 `1,2,3`。移动可以输入常用目的地编号，或精确坐标，例如 `D6`、`G6`。
4. **查看自动预览**：确认成本、影响、命中率或豁免概率，以及危险、专注替换或借机攻击。
5. **执行或返回**：输入 `c` 确认，输入 子菜单中 `0` 返回上一层重新选择。输入 `q` 随时离开。

数字始终只选择当前显示的条目，预览页输入数字不会提交行动。攻击、治疗、移动等普通行动后仍保留当前角色；“结束操作”确认后切换到下一位可操作角色。所有实际行动仍由规则核心校验与结算，菜单不能绕过视线、射程、资源或版本限制。

目标列表显示名字、生命、距离与相关概率，并保留不可用目标及具体原因，例如“遮挡”“超出射程”。选中不可用目标不会写入或推进战斗。已死亡敌人不再作为攻击或施法目标。治疗的效果无需命中检定；圣火显示敌方豁免失败概率；自动命中的法术会注明确定效果。多目标技能仍逐项检查目标，最终预览计算整个目标组合。

距离使用包含地形高度的三维直线计算，供射程判断；移动成本使用实际可走路径，二者可能不同。例如 P2 位于 K4 台阶（高 1.5 米），E3 位于 L4 高台（高 3 米）：水平距离 1.5 米、高差 1.5 米，直线距离为 `√(1.5² + 1.5²) ≈ 2.12 米`，因此超出 1.5 米的近战触及。移动只走相邻可通行格，还要计入困难地形和绕行，不以这个直线距离扣除移动。

反应暂停战斗时显示中文菜单：`1` 选择接受、`2` 选择拒绝，随后用 `c` 确认，`0` 返回重新选择。离开后待选反应仍保存在规则核心，重新启动会恢复到同一反应窗口。

## 看地图和移动

地图的列从左至右为 A、B、C……，行从上至下为 1、2、3……。地图格使用固定三字符宽度的 ASCII 符号，并用 `|` 分隔每格，避免连片墙、高台或危险地面粘在一起。`P2*` 等带 `*` 的角色编号表示当前选角。旁边的图例将符号对应到角色编号、中文名称、墙 `#`、困难地形 `:`、危险地面 `!`、台阶 `/`、高台 `^` 及门洞 `<>`。颜色仅为辅助，没有颜色仍能识别。角色名字不放进地图格，避免中文文字宽度导致错位。死亡敌人不占格，尸体在图外另列，原位置可正常通行。

简短局势说明会解释断墙、门洞、台阶、高台与遮挡关系。西侧队员应先接近门洞，穿过断墙后可接近瞭望台台阶；射程足够仍可能被墙或高差挡住射线。隐藏敌人不会出现在地图或选项中。

选择“移动”后，地图用 `+` 展示按真实合法路径计算的本回合可达格子；`+!`、`+^` 等组合同时保留危险或高台地形。困难地形、台阶、高差和已知占位都参与计算。常用目的地同时显示到达成本、本回合能否到达及战术作用；不可达目的地保留原因。选择目的地后自动显示整条路径、移动成本、沿路危险地面和可能遭到的借机攻击，确认后才移动。当前只支持编号和坐标选格，方向键选格尚未实现。

默认输出保留战术摘要与本次结果。首次选择角色会展示简短作用；普通行动后显示紧凑菜单，保留全部技能、成本、剩余资源和不可用原因。行动菜单的“技能与规则说明”“详细日志”“队伍资源”“地图”可以按编号展开；也可输入 `party` 查看队伍资源、`map` 重看地图、`inspect G6` 查看格子，或 `log 10` 展开最近计算明细。

## 一次试玩示例

```powershell
python -m client --new --seed 42
```

首页选择 **3 号法师**，在行动菜单选择“移动”，输入 `G6`，查看路径并输入 `c`。在法师菜单选择“火焰箭”，输入一个可用敌人的编号，查看命中率并确认。在法师初始位置直接施法会遇到断墙遮挡，目标菜单会说明原因。用 `0` 可以从预览返回目的地或目标列表，从列表返回行动菜单，再返回首页。

继续选其他角色：武僧先武器攻击后会开放附赠徒手攻击；战士可用回气，牧师可选择治愈真言、疗伤术或祝福。结束某角色操作后系统选中下一位；敌方行动触发反应时按反应菜单选择并确认。战斗所有动作与反应都自动保存。这里的行动、目标编号以当前显示为准，局势变化后可能不同。

## 胜利之后

击败全部敌人后，自动进入独立战后菜单，角色操作入口结束。当前内容仅有这一场前哨战，没有下一关、升级、商店或可拾取的尸体掉落。

| 编号 | 操作 |
| --- | --- |
| `1` | 全队短休：显示每名队员的恢复预览，`c` 确认一次为全队休息 |
| `2` | 查看队伍生命、法术位与资源 |
| `3` | 用当前阵容重开新周目，`c` 确认后新建独立存档 |
| `4` | 查看战场地图，尸体另列且不挡路 |
| `5` | 展开详细日志 |
| `6` | 查看战利品说明；本场未配置掉落，不能摸尸体 |

短休每次消耗 **全队共用的 1 次短休**，本周目共两次；所有存活队员恢复一半最大生命（向上取整并受生命上限限制），恢复战士回气等可短休资源。短休可以救起倒地队员，但不能复活已死亡队员；不恢复法师与牧师的法术位，也不补充药水。它无需逐个选择角色。预览不扣资源，`0` 取消回到战后菜单；次数用尽时仍显示原因。

选择重开周目并确认，会保留队伍名称和四名队员的职业，重新开始本场前哨战；原周目保存在数据库中，屏幕显示旧周目 ID，之后可用 `python -m client --run 旧周目ID` 查看。取消重开不会创建存档。新周目 ID 会成为默认恢复对象。也可输入 `q` 保存胜利结果并离开，或使用命令行 `python -m client --new --seed 42` 重新试玩。

## 预览过期与意外退出

每个预览绑定存档模块状态版本。执行前读取最新视图；其他终端改变局势时拒绝提交过期预览，并提示重新选择、重新预览。也可重新输入 `preview` 快捷命令。返回、取消、读请求、菜单选项和预览不会消耗资源或随机数。

写入前将请求 ID、状态版本和原始命令保存到同目录的 `client.pending.json`。如果保存后进程意外退出，存档可能已经提交动作；此时只能输入 `resend` 或数字 `9`，客户端会重发完全相同的请求和 ID。重输同一个未确认的 `do 编号` 也复用原请求。存档模块返回已有回执，不会再次攻击或掷骰。

退出时保留未确认请求；下次启动自动重发原请求，恢复回执后删除该记录。未确认请求存在时不能新建周目、切换数据库或提交其他动作；必须先恢复原回执。不要删除恢复记录后重新提交相同动作。`retry` 会明确恢复战前游戏状态，与 `resend` 的操作回执恢复不同。


## M3成长、装备与独立试玩

推荐开发验收：`python -m tools.dev_play --level 5`，或 `--levels 2,3,4,5`。只在临时目录保存开发数据库与客户端记录，启动时打印恢复命令。`--equip P1:off_hand:none --equip P1:main_hand:greatsword` 可验证双手武器；`--prepare P3:magic_missile,fireball` 验证取消准备后的限制。

`party` 显示中文装备、属性、熟练、额外攻击、法术位、准备与职业资源。胜利结算的7–10号分别进入P1–P4成长装备菜单；可固定升级、穿戴、卸下、切换准备、奥术回想。每次选择先预览，`c`确认，`0`取消。开发局另有11号重新演练，沿用当前等级/装备/准备并刷新资源，普通周目无该入口。

快捷预览：`preview levelup P1`、`preview equip P1 off_hand none`、`preview equip P1 main_hand greatsword`、`preview prepare P3 magic_missile,fireball`、`preview recover P3 2`、开发局`preview practice`，再`do 编号`。升环仍可用 `preview cast P3 magic_missile E1 slot=3`；群体法术无需目标，例如 `preview cast P4 aid slot=3`。这些命令本地完全共用预览和确认事务。

本轮胜利后的升级是安全阶段的逐级验证入口，没有战役经验节点。新开普通独立周目仍从1级开始；开发局“重新演练”保留新成长与装备。独立演练没有战役奖励或下一关；战役玩法见上方M4说明。

## 推进 A/B：自由目标与装备奖励（2026-10-23）

- 选择魔法飞弹/灼热射线后：单个编号把全部攻击分给该目标；输入 `1,1,2` 为三段逐个分配，允许重复。升环须给足对应段数，可继续用快捷命令指定 `slot=3`。每段预览分别显示命中、伤害骰及已知抗性；执行时目标先死，其剩余段跳过，其他已分配目标继续，不自动转火。
- 选择火球后：直接输入地面坐标（如 `G6`、`E6`），也可选择敌人编号作为爆心。预览显示爆心、6米半径及可见受影响目标的豁免；范围内隐藏敌人仍真实受伤，但不进入预览与结果日志。
- 5级武僧新增震慑拳：一次近战攻击，可接续额外攻击；命中才耗1气。体质豁免失败震慑到施术者下一次回合结束；无法行动/移动/反应，来袭攻击优势，力量与敏捷豁免自动失败。
- 商店按战役阶段补货；购买与换装预览显示当前→候选的伤害骰、攻击加值、AC、速度、法术命中/DC、治疗加值与资源上限，并显示熟练、双手互斥、武艺/施法限制。要塞双门胜利发一次职业装备奖励，进入背包后手动穿戴。物品特效见预览全文。

```text
preview cast P3 magic_missile E1,E1,E2
preview cast P3 scorching_ray E1,E2,E3,E3 slot=3
preview cast P3 fireball at=E6
preview ability P2 stunning_strike E1
preview buy P3 focus_staff
```

`at=E6` 明确表示地面，避免快捷命令把 E6 当敌人编号；数字菜单中的坐标没有此歧义。仍须 `c` 确认。

反复试玩真实熔炉地图，默认四人5级、使用独立临时存档：

```powershell
python -m tools.dev_play --battle-slice --ui cards
python -m tools.dev_play --battle-slice --equip P2:main_hand:wind_staff --equip P3:main_hand:focus_staff
```

胜利后11号重新演练会保留熔炉场景、等级、装备和准备法术，刷新生命与资源；可重新配置后再打。无金币奖励，不读取正常玩家存档。


## 八级Boss试玩与成长记录（2026-10-26）

`python -m tools.dev_play --boss-slice --ui cards` 直接开启四人8级Boss战，独立临时数据库；胜利后11号重新演练保留Boss场景、成长、准备和配装。`--level 7` 可改等级（1–8），原 `--battle-slice` 默认仍为5级熔炉。

每次升级预览/结算显示新能力、被动、HP、属性、法术位和职业资源的变化。战后7–10号打开角色成长页可看最近升级，17号查看全队记录；随时输入 `growth` 看全队，`growth P1` 看单人完整已保存记录。卡片模式结果区可用 `]/[` 翻页。旧档未保存的历史不会补造。

新装备位 `ring` / `feet` 对应戒指与鞋子，商店购买后进入7–10号穿戴；原 `--equip P1:ring:protection_ring --equip P1:feet:swift_boots` 也可用于独立开发试玩。护甲/盾牌熟练与武僧无甲限制仍有效，戒指和鞋子不算护甲。
