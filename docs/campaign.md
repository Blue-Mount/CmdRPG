# M4 五站战役雏形

2026-10-18。四职业、1–5级、每条路线五场战斗；六个遭遇节点。原计划20场、六职业八级仍是长期目标。

```text
前哨 Lv1 ─┬─ 灰烬旧道 Lv2 ─┐
          └─ 北侧山脊 Lv2 ─┴─ 要塞双门 Lv3 → 熔炉守军 Lv4 → 裂隙之心 Lv5
```

六张16×12地图分别配置墙体、通道、火地面、困难地面或高差。山脊有连续的台阶落脚点和高台，纯近战能走到射手身旁。最终 Boss 烬王有110生命、15防御和2d6基础伤害，带两名守军；没有第二阶段或专属技能。熔炉中熔甲守卫有火焰抗性、游击手熟练敏捷/体质豁免、熔火术士使用12米熔火箭（2d6火焰，敏捷DC13，成功减半）；可见敌人的已知规则可用 inspect 查看，不提供未来行动。

## 开始与操作

`python -m client --campaign --seed 42` 新开独立战役周目，保留已有周目。首页9/战后12也可建战役；`--new` 默认仍是独立前哨战。四职业允许重复。战役不接受开发局高等级/任意装备开局。

隔离试玩：`python -m tools.dev_play --campaign`；临时目录包含数据库和周目记录。启动时输出恢复命令；退出后目录保留。测试只使用临时数据库。

战后13/14选择可用路线，15营地，16商店，7–10查看各队员装备与法术准备。路线仅在当前关胜利后开放；不能跳关、返回已完成关或重复刷奖励。所有写操作先预览，再按 `c`；`0`取消。

## 成长与经济

- 初始40金币；每场奖励 `60 + 20 × 站数` 金币，胜利时自动发放一次。
- 前四场胜利后全队依次升到2、3、4、5级，保留资源消耗和倒地/死亡状态；不能在菜单中越级。Boss后维持5级。
- 每站胜利后可花20金币休整一次：全队复苏、生命/法术位/职业资源全恢复，清除临时效果，短休次数恢复为2；药水不补充。
- 短休不花金币，使用剩余次数，恢复半数最大生命和短休资源；不恢复法术位或死亡队员。
- 商店按进度补货：药水10、巨剑35；第一站胜利后开放精钢长剑55、踏风杖45、凝劲杖55、聚能法杖60、守御法杖45、仁心权杖50；第二站追加堡垒盾70；第三站追加破阵巨剑90、板甲100金币。物品进入指定队员背包；药水立即增加数量，装备须手动穿戴。装备不能重复购买；无售卖系统。
- 商店允许自行决定是否保留营地的20金币，不足时会在购买预览提示；营地价格维持20。进入下一站前，四名队员必须都清醒。
- 初始背包只含所穿装备；独立开发演练仍保留自由装备试验。要塞双门首次胜利，为每名战士/武僧/法师/牧师分别发放精钢长剑/踏风杖/守御法杖/仁心权杖（已拥有不重复发），不会自动替换当前装备。

进入下一站保留等级、装备、准备法术、背包、药水、生命和剩余资源，移除上一场临时效果并重置先攻。战败重试恢复本关战前快照，包括金币、路线、装备与随机数；已结算前关不会重新发奖励。Boss及亲卫全部败北后显示通关，12号可另开战役，原结局保留。

## 兼容与范围

战斗规则仍为 `0.3.0-provisional`；独立局内容版本保持 `0.3.0-m3`，战役存档内容版本为 `0.4.0-m4`，另有战役数据版本 `1`。既有独立存档不自动转为战役，不隐式领取奖励。战役版本不匹配明确拒绝读取，旧M3程序也会拒绝新战役存档，避免回退后错误结算。

新增创建字段 `campaign: true`；战役视图字段 `campaign` 提供进度、金币、可选路线和商店。`travel` / `camp` / `buy` 经原有预览、版本检查、事务和幂等回执执行。换机时先更新游戏代码，再按需通过 GitHub 下载存档。

尚未包含20场内容、八级成长、剧情分支结局、专属Boss技能、人工五小时节奏校准和实际异地网络验收。
