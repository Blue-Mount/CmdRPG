# 七站战役与两阶段Boss

更新：2026-10-27。四职业、1–8级，新周目每条路线七场战斗，共八个遭遇节点。六职业、20场仍是后续目标。

```text
前哨 Lv1 ─┬─ 灰烬旧道 Lv2 ─┐
          └─ 北侧山脊 Lv2 ─┴─ 要塞双门 Lv4 → 熔炉守军 Lv6 → 断桥交火 Lv8 → 回响大厅 Lv8 → 裂隙之心 Lv8
```

八张16×12地图分别配置墙体、通道、火地面、困难地面或高差。山脊有连续的台阶落脚点和高台，纯近战能走到射手身旁。最终Boss烬王180生命、16防御、2d8基础武器伤害，带两名守军。生命降至一半且仍存活时进入裂隙化身：获得火抗，改用6米范围震荡或18米单体火矛（3d6火焰、敏捷DC15成功减半）。转阶段只触发一次，保留震慑与行动预算，可以被爆发直接击杀。熔炉中熔甲守卫有火焰抗性、游击手熟练敏捷/体质豁免、熔火术士使用12米熔火箭（2d6火焰，敏捷DC13，成功减半）；可见敌人的已知规则可用 inspect 查看，不提供未来行动。

断桥交火的射手分处可步行抵达的南北高台，中央有重卫与豁免型术士；回响大厅有成组突袭者、火抗重卫与后排术士。两场保持歼灭目标，可通过爆发、控制、AOE、机动等不同打法完成，支持每站营地恢复。

## 开始与操作

`python -m client --campaign --seed 42` 新开独立战役周目，保留已有周目。首页9/战后12也可建战役；`--new` 默认仍是独立前哨战。四职业允许重复。战役不接受开发局高等级/任意装备开局。

隔离试玩：`python -m tools.dev_play --campaign`；临时目录包含数据库和周目记录。启动时输出恢复命令；退出后目录保留。测试只使用临时数据库。

战后13/14选择可用路线，15营地，16商店，7–10查看各队员装备与法术准备，17查看全队升级记录。路线仅在当前关胜利后开放；不能跳关、返回已完成关或重复刷奖励。所有写操作先预览，再按 `c`；`0`取消。

## 成长与经济

- 初始40金币；七站依次奖励80/100/120/140/160/180/160金币，胜利时自动发放一次。
- 前四场胜利后全队依次升到2、4、6、8级，保留资源消耗和倒地/死亡状态；不能在菜单中越级。Boss后维持8级；跨级时逐级显示收益，`growth P1`可回看已保存记录。
- 每站胜利后可花20金币休整一次：全队复苏、生命/法术位/职业资源全恢复，清除临时效果，短休次数恢复为2；药水不补充。
- 短休不花金币，使用剩余次数，恢复半数最大生命和短休资源；不恢复法术位或死亡队员。
- 商店优先展示防具饰品：精制鳞甲55、守护戒指65、瞄准指环55、回春指环45、轻捷靴50金币，第一站胜利可买；第二站追加护符盾60、坚心靴50。戒指与鞋子各一独立槽，无熟练要求，不影响武僧无甲收益。原商品按进度补货：药水10、巨剑35；第一站胜利后开放精钢长剑55、踏风杖45、凝劲杖55、聚能法杖60、守御法杖45、仁心权杖50；第二站追加堡垒盾70；第三站追加破阵巨剑90、板甲100金币。物品进入指定队员背包；药水立即增加数量，装备须手动穿戴。装备不能重复购买；无售卖系统。
- 商店允许自行决定是否保留营地的20金币，不足时会在购买预览提示；营地价格维持20。进入下一站前，四名队员必须都清醒。
- 初始背包只含所穿装备；独立开发演练仍保留自由装备试验。要塞双门首次胜利，为每名战士/武僧/法师/牧师分别发放镇门者之刃/奔雷行者杖/符文壁垒法杖/守曦权杖，商店不售，兼具职业相关的组合收益（详见[专属奖励](playtest-feedback-2026-10-26.md)）；已拥有不重复发，不会自动替换当前装备。已结算要塞的旧周目保留原奖励，不追发。

进入下一站保留等级、装备、准备法术、背包、药水、生命和剩余资源，移除上一场临时效果并重置先攻。战败重试恢复本关战前快照，包括金币、路线、装备与随机数；已结算前关不会重新发奖励。Boss及亲卫全部败北后显示通关，12号可另开战役，原结局保留。

要塞胜利后新增商品：精准戒指85（主手武器攻击命中+2，不加成附赠徒手/疾风连击或法术）、织法戒指90（法术DC+2）、蓄气戒指80（2级以上武僧气点上限+2）、远行长靴95（移动+6米）。戒指相互占位；鞋子与现有鞋子相互占位。气点穿戴不补充，卸下会限制当前气至较低上限，短休/营地才能恢复至上限；升级保留已消耗量。

## 兼容与范围

当前规则 `0.6.0-provisional`；独立局内容 `0.6.0-m6`，战役内容 `0.6.0-campaign`，SQLite/JSON格式与战役数据版本仍为1。兼容历史精确版本组合，只读与预览不迁移；成功写入时更新外层版本。已存角色、地图和战前快照保留，已进入的旧Boss不自动替换，已结算的要塞不追发奖励。换机与回退前核对代码版本。

新周目的战役路线edition为2；未记录edition的历史周目保持edition1的五站节点、原地图与最终战，不插入新战斗。旧0.5.0版本组合可继续游玩，显式操作后才更新外层版本，路线edition保持原值。

新增创建字段 `campaign: true`；战役视图字段 `campaign` 提供进度、金币、可选路线和商店。`travel` / `camp` / `buy` 经原有预览、版本检查、事务和幂等回执执行。换机时先更新游戏代码，再按需通过 GitHub 下载存档。

尚未包含20场内容、六职业、剧情分支结局、完整职业技能包、人工五小时节奏校准和实际异地网络验收。
